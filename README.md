# IBM Db2Hack 2026 Submission

This repository contains the citizen grievance portal submission for **IBM Db2Hack 2026**.

The complete project and submission artifacts live in:
👉 **[`submissions/grievance-db2/`](submissions/grievance-db2/)**

### Quick Start
To launch the complete application (IBM Db2 Community Edition, FastAPI backend, and Nginx frontend):

```bash
cd submissions/grievance-db2
docker compose up --build
```

(Or directly from the repository root: `docker compose up --build`)

For detailed technical architecture, schema documentation, and API specifications, see:
- [`submissions/grievance-db2/README.md`](submissions/grievance-db2/README.md)
